# 🌐 TodasIA — Directorio de herramientas de IA en español

**[todasia.com](https://www.todasia.com)** — El directorio de inteligencia artificial en español.

[![Tools](https://img.shields.io/badge/Tools-112-green)](https://www.todasia.com/ranking)
[![Next.js](https://img.shields.io/badge/Next.js-16.2-black)](https://nextjs.org)

## Sobre

Directorio independiente de herramientas de IA para hispanohablantes de España y Latinoamérica. Incluye herramientas globales con soporte en español y herramientas hechas en España.

## Funcionalidades

- **112 herramientas** catalogadas con descripciones, pros/contras y precios
- **20 categorías** (Chat IA, Imágenes, Escritura, Programación, Video, Audio, etc.)
- **Favoritos** — guarda herramientas para más tarde
- **Comparar** — compara 2–4 herramientas lado a lado
- **Ranking** — ordenado por valoración
- **Alternativas** — herramientas similares a cada ficha
- **Búsqueda** — por nombre, categoría o descripción
- **Blog** — artículos en español
- **Dark mode** — tema claro y oscuro
- **Mobile-first** — responsivo en todos los dispositivos

## Stack

- **Framework:** Next.js 16 (App Router)
- **Estilo:** Tailwind CSS 4
- **Hospedaje:** Vercel
- **Analytics:** Google Analytics 4 + Vercel Web Analytics

## Ejecutar localmente

```bash
git clone https://github.com/haojiang2013/todasia.git
cd todasia
npm install
npm run dev
```
